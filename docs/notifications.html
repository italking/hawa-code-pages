通知

Hawa Code 支持 Web 通知功能。当你已经打开 Hawa Code Web 端控制台，但当前浏览器窗口或标签页不在前台时，如果需要确认某个工具调用，Hawa Code 会通过系统通知及时提醒你。

开启方式

Web 通知需要先在浏览器中授予权限才能使用。你可以通过以下任一方式开启。

在工具执行确认窗口中开启

当 Hawa Code 执行需要确认的工具时，确认窗口底部会出现 Enable notifications 按钮。点击后即可授权浏览器在页面隐藏时发送后台通知。

在浏览器设置中手动开启

如果你未在确认窗口中开启通知，也可以在 Chrome 或 Edge 中手动添加站点授权：

  1. 在浏览器地址栏输入以下 URL 并打开：
    chrome://settings/content/notifications
  2. 添加 Hawa Code 站点地址。
  3. 允许该站点发送通知。

完成授权后，当需要确认工具调用时，Hawa Code 会自动弹出系统通知。
