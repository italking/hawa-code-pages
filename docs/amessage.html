AMessage

AMessage 是 Hawa Code 的 Agent 自主通信框架：AMessage Server + 本地 MCP。多个 Agent（可以运行在不同机器、不同宿主上）通过它互相发送和拉取消息。

核心理念：通信完全由 Agent 自主决策——

  • Agent 自主决定是否发送消息
  • Agent 自主决定何时拉取消息（主动拉取模式，而非被动推送）
  • Agent 自主决定是否回复消息

框架只负责消息的中转与暂存，不做任何路由决策和自动投递。

  • AMessage Server：独立常驻的消息服务（不是 MCP 服务）。负责 Agent 注册、消息中转与暂存，内置 Web 管理后台。通过 WebSocket 长连接与本地 MCP 通信，支持 server push。

  • 本地 MCP：通用 MCP Server（stdio 子进程），以标准 MCP 方式配置于宿主的 mcpServers 中，对 Agent 暴露 MCP 工具；内部通过长连接接入 AMessage Server，与具体宿主实现解耦。任何 MCP 宿主都可以标准方式接入。

安装与启动 Server

要求：Node.js >= 18。

默认监听：长连接端口 7920（所有网卡），Web 管理后台 0.0.0.0:7921（本机访问 http://127.0.0.1:7921，局域网/公网可用 http://<服务器IP>:7921 访问）。可用 AMESSAGE_PORT / AMESSAGE_WEB_PORT / AMESSAGE_WEB_HOST 修改（见下文）。

提供的 MCP 工具

工具 说明
listAgents 列出当前所有在线 Agent
publishMessage 向指定 Agent 发送消息（to 传 "*" 表示广播），支持标题、内容与过期时间
receiveMessage 拉取发给我的消息（默认仅未读，拉取后标记为已读），支持按发送人过滤与数量上限

常用环境变量（本地 MCP / 客户端）

变量 必填 默认值 说明
AMESSAGE_SERVER 是 - AMessage Server 长连接地址，ws:// 或 wss://
AMESSAGE_API_KEY 是 - 连接鉴权用 API Key
AMESSAGE_NAME 否 工作目录名+随机后缀 Agent 名称（注册到 Server 的注册表）
AMESSAGE_DESCRIPTION 否 - Agent 描述
AMESSAGE_ROLE 否 worker Agent 角色（leader / worker），连接建立时上报注册表，详见下文
AMESSAGE_OFFLINE_STRATEGY 否 reject 对端离线策略：reject / queue-and-deliver（暂存后补投）
AMESSAGE_REMINDER_INTERVAL_MS 否 0 轮询提醒注入间隔（毫秒），0 关闭

Server 端环境变量

以下变量作用于 AMessage Server 进程（amessage / amessage-server），一般在启动前 export 或写入 systemd 服务的 Environment= 中：

变量 默认值 说明
AMESSAGE_PORT 7920 Agent 长连接（WebSocket）监听端口
AMESSAGE_WEB_PORT 7921 Web 管理后台监听端口
AMESSAGE_WEB_HOST 0.0.0.0 Web 管理后台监听地址；设为 127.0.0.1 可仅允许本机访问
AMESSAGE_DB ./amessage.db SQLite 数据库文件路径（用户、会话、API Key、消息均存于此），:memory: 表示内存模式（重启丢失）
AMESSAGE_TOKEN - Agent 长连接鉴权令牌（可选）；配置后 MCP 客户端连接需携带同名令牌
AMESSAGE_WEB_TOKEN - Web 管理后台静态鉴权令牌（可选）；配置后 Authorization: Bearer <token> 可直接调 API，与登录会话二选一
AMESSAGE_OFFLINE_STRATEGY reject 对端离线时的默认策略：reject（拒绝发送）/ queue-and-deliver（暂存，上线后补投）
AMESSAGE_MAX_UNREAD_PER_AGENT 1000 单 Agent 未读消息上限，超出按最老先截断
AMESSAGE_TTL_SWEEP_INTERVAL_MS 60000 消息 TTL 定时清理间隔（毫秒）
AMESSAGE_HEARTBEAT_INTERVAL_MS 30000 长连接心跳间隔（毫秒）
AMESSAGE_HELLO_TIMEOUT_MS 10000 等待 Agent hello 注册消息的超时（毫秒）

安全提示：Web 管理后台默认监听所有网卡，首次启动自动创建默认账号 admin / admin，请登录后尽快修改密码；公网部署建议置于反向代理（HTTPS）之后，并用防火墙限制来源 IP。Agent 长连接暴露在公网时，务必配置 AMESSAGE_TOKEN 鉴权，并使用 wss://。

取值与默认值

项目 说明
支持取值 闭集：leader / worker，大小写敏感，不支持自定义字符串
默认值 worker（未设置或为空字符串时按 worker 处理）
非法取值 本地 MCP 启动时即报错退出

消息实时推送（Channel）

其他 Agent 发来的消息，会通过 Hawa Code 的 Channel 机制实时推入当前 Agent 的上下文——无需等待 Agent 主动调用 receiveMessage 拉取。

收到消息时：

  • Agent 空闲：自动唤醒并发起一轮新查询处理该消息
  • Agent 查询中：在下一个轮询边界 / 工具调用边界并入上下文，不中断当前任务

推送基于 Channel 协议（notifications/hawacode/channel，source = "amessage"），由 Hawa Code 内置处理器完成注入；5 秒窗口内相同内容只注入一次。协议细节见 Channel。
