How Hawa Code Code Mode Eliminates the Software Development Process

2026-10-11 hawa code

AI Coding is evolving rapidly and has overturned many development paradigms. However, software still has to be developed before it can be used. Vibe coding allows people without IT skills to build software, but they still have to develop a piece of software first and then use it.

Hawa Code’s philosophy is that users don’t need to deliberately develop a piece of software. They only need to talk to Hawa Code to solve their problems. Hawa Code progressively generates a piece of software to solve the user’s problem, so that the model inference step is gradually replaced.

A Simple Example

Let’s look at the underlying mechanism through a simple example.

First Run

Give Hawa Code the following instruction:

Count the total number of commits across all Java projects on my GitHub account, excluding forked repositories, and count only commits authored by myself, not by others.

The main execution logic of Hawa Code Code Mode is as follows:

  • Search for the required APIs
  • Get detailed API information
  • Perform the business query and return the result
  • At the same time, save the business code for this generic scenario

Second Run

When Hawa Code receives a similar instruction again, it executes the following logic:

  • Search for APIs
  • It finds code that can solve the current problem, executes that code, and returns the result — no more inference.

How It Works

While processing a user’s problem, Hawa Code abstracts the problem into a generic scenario, generates code, and saves it. When a similar problem comes up again, it executes the code directly instead of relying on inference to solve the problem. Under the hood, Code Mode is built on a set of basic APIs that can be extended manually. These APIs are like the SDK for mobile app development: the generated code wraps a new layer of API on top of the SDK, and these code APIs can in turn be called by other code. Ultimately, this can support complex applications.

The example above is just a simple one. In a follow-up article, I will write about train ticket queries: the user simply uses Hawa Code in various ways to query train tickets — for example, “next Saturday from Beijing to Hangzhou, must pass through Liyang Station, the train with the shortest travel time.” Through repeated queries, Hawa Code gradually generates a complete train ticket query application.

Inference Cost vs Determinism

The current cost of model inference is still very high, while executing code is much cheaper. At the same time, inference is very slow, while code execution is much faster. Mixing inference with code execution allows an Agent to support complex, high-traffic businesses at a very low cost.

Model inference is “probabilistic.” In many scenarios, tolerance for uncertainty is extremely low — for example, in trading, transfers, and payments, there can be no margin of error at all. Turning logic into code makes the uncertain deterministic.

Customization

Traditional IT software is mostly generic and replicable. But in the AI era, Agent assistants are customized — everyone will have an intelligent assistant that matches their personality and work habits. Yet the “customization” step is not needed: the Agent assistant grows into the shape you need based on your behavior.

What Does Hawa Code Aim to Achieve?

Reliable Quality

Automatically accumulated code must be reliable. Hawa Code does not save newly generated code directly — it only saves code that has already solved a real user problem. Before being saved, this code has already been tested and verified. And when the business changes, Hawa Code will also correct the code accordingly.

Rich BaaS Services

Currently, Hawa Code Code Mode supports MCP service extensions, using MCP as APIs for code development. In the future, it will also support local scripts, databases, storage, and other local services. It will also integrate third-party services such as Supabase and Appwrite by default.

Model Routing

When Hawa Code receives a user instruction, a very small model performs business intent recognition. If the instruction can be solved by executing code in Code Mode, no inference is performed. Only when there is no relevant code will it be routed to a large model for inference. These very small models may even run directly on the user’s own machine rather than in the cloud.

UI Interaction

Currently, Agent model interactions are mostly in Markdown format, which is weak for displaying complex information. For example, when querying product information, the result should be a beautiful product image list page like in a browser. Hawa Code already works in the browser, and Code Mode will support returning rich HTML content in the future, enabling a better interactive experience.
