Hawa Code Web Control 全新升级、远程控制、Team 协作

2026-08-23 hawa code

Hawa Code Web Control 全新升级，交互更加便捷易用。基于浏览器即可随时随地远程访问，兼容 PC、手机等多种终端。支持多用户共享，一个 CLI 终端可在多个浏览器端同步使用，满足开发者多人协作与共享使用的需求。

开启方式

在 cli 终端使用 hcode 命令启动 Hawa Code ，使用 /config 斜杠命令 启用 Web Server ，在浏览器中输入提示地址 http://127.0.0.1:3210 进行访问，每一个 cli 终端会使用单独的 Web Server ，端口号会递增。

Agent view

Agent view 可以查看任意 Agent 消息内容，包含用户 Prompt、Tool 调用、模型响应。

  • Agent view 支持输入 Prompt 语句，控制 Agent 执行并且可以中断 Agent 执行。
  • Agent 列表显示时当前 cli 全部 Agent 、绿色表示活跃 ，灰色表示已经结束。刷新页面后已经结束的 Agent 信息不会被保留。

点击右侧 Agent 可以切换查看不同的 Agent 执行情况。

Settings

在 Settings 中可以修改 cli 的配置、包含代理、懒加载、语音、插件市场配置、auto mode、记忆、模型 token 配置等信息。

欢迎了解使用 Hawa Code （https://www.hawacode.com/） 一个懂你的编程助手！
